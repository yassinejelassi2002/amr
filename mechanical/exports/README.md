# Exports

CAD file exports including STEP, STL, drawings, and renders.

## Purpose

Store exported CAD data suitable for manufacturing, simulation, and documentation.

## Subfolders

- `step/` - STEP format files for CAD interchange
- `stl/` - STL format files for 3D printing and simulation
- `drawings/` - PDF technical drawings
- `renders/` - Visualization renders and concept images
