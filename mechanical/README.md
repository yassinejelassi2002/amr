## Git Storage Policy

Active CAD files (proprietary formats) are not stored in Git at the beginning. Store only:

- Exported STEP files
- Exported STL files
- PDF drawings and technical documentation
- Rendered images and concept visualizations
- Design concept notes

## Future Work

- Chassis design and optimization
- Modular add-on mounting standard
- Payload capacity and assumptions
- Serviceability and maintenance notes
- Material and manufacturing process specifications

## Subfolders

- `concepts/` - Design concepts and sketches
- `dimensions/` - Mechanical specifications and constraints
- `mounting_interface/` - Modular add-on interface design
- `exports/` - STEP, STL, drawings, and renders
