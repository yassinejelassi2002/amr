# Agent Rules

## Purpose

This file defines rules for AI coding agents working on AMR-X.

## Scope

AMR-X is currently in documentation and product-definition restructuring. Do not create robot runtime code unless the user explicitly asks for it.

## Required Workflow

Follow this path for repository work:

Issue -> Branch -> CSV/TEX edit -> Generate tables -> Pull request -> Review -> Merge

For local repair tasks, keep edits aligned with that workflow even when no issue number is provided.

## Source of Truth

- Global project specifications live in `config/project_specs.json`.
- BOMs live in `data/bom/`.
- Component candidates live in `data/components/component_candidates.csv`.
- Module decisions live in `data/modules/module_decision_matrix.csv`.
- Module interface requirements live in `data/modules/module_interface_requirements.csv`.
- Requirements live in `data/requirements/requirements_matrix.csv`.
- Final LaTeX reports live in `reports/market_study/` and `reports/v1_product_definition/`.
- Legacy docs live in `references/legacy_docs/`.

## Agent Rules

- Follow the user request exactly.
- Do not add unrequested features.
- Do not invent market data, prices, suppliers, citations, or technical specifications.
- Use `TBD` for undecided values.
- Do not duplicate global payload, dimension, speed, endurance, or interface values in report prose.
- Do not manually edit generated LaTeX tables.
- Run `python3 tools/generate_specs.py` after changing `config/project_specs.json`.
- Run `python3 tools/generate_latex_tables.py` after changing CSV files under `data/`.
- Keep generated report PDFs and LaTeX build outputs out of git.
- Do not commit private PDFs or restricted supplier documents.

## Decision Rules

Every major base component and module must have a build, buy, modify, or custom-manufacture decision recorded in the controlled CSV files.

## Review Rules

Before finishing, check:

- Required files exist.
- CSV sources and generated LaTeX tables are consistent.
- `docs/technical/` has not been recreated.
- Generated build artifacts are not in report source folders.
