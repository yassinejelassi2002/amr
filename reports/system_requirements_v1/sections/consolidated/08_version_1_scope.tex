\chapter{Version 1 Scope}

\section*{i. Document 1}

\subsection*{In scope for Version 1}

\begin{enumerate}
    \item A custom mobile base purpose-built for warehouse environments.
    \item Manual control and/or basic autonomous navigation.
    \item Basic obstacle detection with automatic slow/stop behaviour.
    \item A payload platform for carrying representative test loads.
    \item Integration of the navigation sensor suite.
    \item Battery and electronics integration with on-board compute.
    \item A modular mounting area for future additions.
    \item Supporting engineering baseline: CAD, bill of materials, wiring, and test records.
\end{enumerate}

\subsection*{Out of scope for Version 1}

\begin{enumerate}
    \item Load manipulation: robotic arms, grippers, lifts, or conveyors.
    \item Full autonomous fleet coordination and warehouse-management-system integration.
    \item Higher payload classes beyond 50 kg.
    \item Full third-party safety certification and unsupervised operation among the public workforce.
    \item Multi-floor operation, outdoor operation, or operation on uneven/unsealed surfaces.
    \item Advanced autonomy such as dynamic re-routing in highly crowded, fast-changing areas.
\end{enumerate}

\section*{ii. Document 2}

Document 2 scopes Version 1 as a functional mobile base with essential navigation sensors, a payload platform, battery monitoring, and modular mechanical interface. Advanced functional units such as robotic arms, inspection sensors, and specialized handling modules remain future expansions.
