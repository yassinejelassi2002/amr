\chapter{Objectives}

\section*{i. Document 1}

\subsection*{Primary mission of the first prototype}

The primary mission of V1 is to design, build, and validate a custom modular mobile base for warehouse environments that can move reliably under manual control and basic autonomous navigation while carrying a representative payload, detecting and stopping for obstacles, and exposing a modular mounting interface for future attachments. V1 is a platform and technology demonstrator. It is explicitly not required to perform a finished commercial logistics task such as picking or palletising; those capabilities are delivered later as modules.

\subsection*{Project objectives}

\begin{enumerate}
    \item Produce a self-contained mobile base sized for warehouse aisles.
    \item Demonstrate both manual control and basic autonomous navigation along a defined route.
    \item Demonstrate basic obstacle detection that reliably slows or stops the robot before contact.
    \item Carry a representative test payload on a dedicated payload platform without loss of stability or mobility.
    \item Integrate navigation sensors, battery, and electronics into a maintainable, documented package.
    \item Provide a standardised modular mounting area for future additions.
    \item Establish the engineering baseline: CAD, BOM, wiring, and test data.
\end{enumerate}
