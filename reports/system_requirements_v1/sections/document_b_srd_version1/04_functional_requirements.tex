3. Functional Requirements

The Version 1 prototype shall implement the following functional capabilities to ensure basic

\section*{warehouse mobility and validation of autonomous operation:}

FR-01 -- Manual Control The robot shall support manual driving mode for testing, calibration, and debugging.

FR-02 -- Basic Autonomous Navigation The robot shall be capable of navigating between predefined waypoints within a controlled warehouse environment.

FR-03 -- Obstacle Detection and Avoidance The robot shall detect obstacles in its path using onboard sensors (e.g., LiDAR or ultrasonic sensors) and adjust or stop its motion to prevent collisions.

FR-04 -- Odometry and Position Estimation The robot shall estimate its position using wheel encoders combined with IMU data.

FR-05 -- Payload Transport Platform The robot shall include a stable platform capable of carrying test loads up to the defined payload capacity.

FR-06 -- Sensor Integration The robot shall support integration of core navigation sensors (LiDAR, IMU, encoders).

FR-07 -- Battery Monitoring The system shall monitor battery status and provide low-battery alerts.
