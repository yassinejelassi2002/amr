\chapter{Scope and Versions}

\section{V1 Study Scope}

V1 is a modular mobile base prototype study for warehouse environments.

The goal of V1 is to define, design, and validate the base platform concept: chassis, drivetrain, battery, electronics, compute, navigation sensors, safety functions, payload platform, and modular mounting interface.

V1 shall study and later demonstrate manual control, basic autonomous navigation, obstacle detection and stop behavior, payload transport, and module mounting readiness.

\section{Provisional Starting Assumptions}

The current study uses \SpecBaseRobotRatedPayloadKg~kg as a provisional starting payload assumption. This is not a final confirmed target.

The current dimensions, speed, endurance, and test values are also provisional. They are used so teams can start comparing concepts, components, and feasibility. These values must be reviewed before final procurement or final mechanical design.

\section{Module Design Scope}

The robotic arm module, shelf-access module, secure delivery compartment module, and sensor-inspection module are part of the internship scope as design work.

Each module shall receive:

\begin{itemize}
    \item Concept design.
    \item Interface definition.
    \item Build, buy, modify, or custom-manufacture decision.
    \item Preliminary component selection.
    \item Preliminary BOM.
    \item Verification approach.
    \item Risk review.
\end{itemize}

Physical implementation priority shall be decided after feasibility, cost, safety, and schedule review. A module may be built from scratch, modified from an existing product, manufactured locally, bought as a subassembly, or deferred if the design review shows that it is not realistic for the current prototype phase.

\section{Not Yet Final}

The following are not yet final:

\begin{itemize}
    \item Payload target.
    \item Robot dimensions.
    \item Motor selection.
    \item Battery size.
    \item LiDAR model.
    \item Compute platform.
    \item Wheel configuration.
    \item Module mounting pattern.
    \item Power and data interface for modules.
    \item Which module will be physically prototyped first.
\end{itemize}
